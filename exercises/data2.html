Data Exercise 2 — Titanic hint

Task: Using pandas (Colab), compute survival rate by sex and by Pclass. Example code:

import pandas as pd
df = pd.read_csv("titanic.csv")
print(df['Sex'].value_counts())
survival_by_sex = df.groupby('Sex')['Survived'].mean()
print(survival_by_sex)
