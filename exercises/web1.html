Task: Create a Simple Web Page

In this exercise, you will create a basic HTML page with the following elements:

  • A main heading (h1)
  • A sub-heading (h2)
  • A short paragraph about yourself
  • A list of 3 favorite hobbies

Save your file as my_page.html inside the Personal_Website folder.

Once done, open the file in your browser to see the result!
