Web Development Exercise 1

In this exercise, you will practice creating a simple HTML page with headings and paragraphs.

Task

Create a new HTML file and write the following:

  • A main heading with your name (use <h1>).
  • A sub-heading with "My First Website" (use <h2>).
  • A short paragraph about yourself (use <p>).

When finished, open the file in your browser to see the result.
